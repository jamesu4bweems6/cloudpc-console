# 进入系统与锁屏连接的区别（2026-10-08）

用户确认官方客户端点击“进入系统”会自动解锁到 Windows 桌面。旧版先将主通道认证计为成功，随后又将收到锁屏画面计为成功，两种判定都不足以证明进入系统或延长自动关机期限。

## 当前成功条件

程序必须同时收到有效 H264 显示帧、来宾登录状态 `16 = 1`，才执行在线业务上报并设置 `systemEntryConfirmed` / `desktopSessionEntered`。状态 0 或其他未解释值不计成功；保持期间重新返回未登录也判失败。完成保持与断开上报后才设置 `success`。

网页只读取过滤后的结果。旧历史中的主通道成功降级为“仅认证”，显示帧成功但缺少登录确认的记录降级为“仅画面”，原始历史文件保留。

## 对照样本还原的流程

位置来自 iOS 3.6.6 的 `uSmartViewDesktopSDK` 静态分析。

| 流程 | 实现依据 |
| --- | --- |
| 普通连接模式 | `send_link!0xde4290` 默认模式 1，链接体偏移 32 |
| 显示初始化 | `0xdfdfb8` / `0xf9f2b4` 的 19 字节 `<BqBiIB>` |
| 显示帧识别 | `314` 显示表面、`122` H264 流、`123` 对应完整帧；仅设置显示就绪 |
| 来宾流控 | MAIN_INIT 发送额度保留到延迟上线的 agent；空 107 不再清零额度 |
| 来宾握手 | 能力交换、143 终端信息、16 登录状态查询；不发送键鼠事件 |
| 自动登录 | 仅在返回参数 `--al 1` 且状态为 0 时，发送一次 82 密码登录类型与 19 来宾登录消息 |
| 登录消息 | `AddSuOperPwdAndNameParm!0x11bfc50`、`user_logon_info!0xe16d50`：URL 编码、票据 MD5 派生 XOR、BE 字段长度 |
| RSA2048 | `init_logon_info_rsa_encrypt_cap!0xe13554` 在消息不超过214字节时声明主通道能力 bit13；`recv_link_msg!0xde54cc` 的314字节扩展头含294字节DER公钥；`deal_rsa2048_encrypt!0xe19a3c` 使用 OAEP/SHA1 |
| 登录后模式 | 状态为1时发送127用户模式3；最多3次状态查询，30秒进入等待上限 |

未实现的编码或通道布局会报告未完成，不伪造进入系统结果。密码登录请求只使用当前目标返回的来宾凭据，记录留在忽略的本地目录。
