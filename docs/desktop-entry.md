## 与样本客户端的差异

以下位置来自 iOS 3.6.6 的 `uSmartViewDesktopSDK` 静态分析，不需要在运行时加载 SDK。

| 项目 | 旧实现 | 本次实现及证据 |

| 附属通道 | 只发送 ATTACH_CHANNELS | 按服务端通道列表建立显示、输入和光标虚拟链接，处理 ACK 和 PING，不发送输入事件 |

## 显示帧确认

本次适配的是已观察到的 ZTE 显示消息：

- `314 / SURFACE_CREATE`：20 字节，记录有效显示表面与尺寸。
- `122 / STREAM_CREATE`：51 字节，记录表面、视频流 ID 和 codec；当前确认 codec 2 的 H264 流。
- `123 / STREAM_DATA`：12 字节头及视频数据，核对流 ID、声明长度和 Annex B 起始码/NAL 类型。

仅有认证、通道列表、显示初始化或未知视频流不会设置 `desktopSessionEntered`。客户端版本采用其他编码或消息布局时，程序会报告未确认进入桌面，需要单独适配。
