# 开机后无法确认登录的修复（2026-10-09）

旧版点击“开机并进入系统”后可能收到Windows锁屏画面，最终报“收到桌面画面，但未确认Windows登录或解锁”。来宾状态保持0，因为登录序列缺少非AD登录模式消息85。

官方iOS 3.6.6 SDK的`cmdline_option_info`位于`0x17bfcf4`，每条记录129字节。记录38将CLI `al`映射到GObject属性`logon-noAD`，记录104将`logon_type`映射到`logon-type`；`spice_parse_command_line!0xe79820`读取该表并设置属性。旧实现误将`--al`用于控制自动登录。官方待处理登录标志在`spice_session_other_init!0xdd3f24`默认置1，与此选项独立。

修复后保留官方参数语义：`--al`非`0`时，先发送85的一字节1，再发送82及19。自动登录待处理标志按官方初始化；RSA能力判断使用实际来宾凭据。参数别名冲突会停止并报错。
