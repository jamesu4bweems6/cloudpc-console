# 本地网页控制台

Docker 部署和现有账号迁移请见 [DOCKER.md](../DOCKER.md)。默认 Docker 网页端口为8766，配置和日志使用独立数据卷。

打开 http://127.0.0.1:8765 查看云电脑状态、登录、单次连接及周期运行。

启动方式（PowerShell）：

```powershell
.\start-web.ps1
```

也可运行 `python web/server.py --port 8765`。仅监听 127.0.0.1，使用本机浏览器访问。运行无需 Node、数据库或前端构建工具，依赖沿用 protocol/requirements.txt。

页面自动读取现存会话；会话有保存不代表它当前仍有效，连接前会交换新 token。账号字段留空会保留现有本地配置；填写后点“保存账号配置”。短信登录先发送验证码，再验证；密码登录若返回可信设备或双因素挑战，会显示设备验证输入框。多企业登录可填写企业用户名。

票据交换或连接前设备查询返回 401 时，会用已保存的账号密码尝试一次续登；成功则继续当前任务和周期连接。设备刷新采用相同恢复流程。没有密码、密码错误或需要短信验证时会停止，网页显示会话失效；请手动登录并重新开启周期连接。自动恢复不发送短信，不重放桌面连接或连接上报。

“立即连接一次”复用已验证的协议脚本，默认保持15秒。“开启周期连接”会立即连接，之后按设定间隔重复；失败会停止。停止周期连接后，已经开始的单次连接会正常完成和清理。关闭网页不会停止服务或周期运行；退出本地服务才会停止未来轮次。重启服务后周期连接默认关闭，不自动恢复。

账号、会话、原始协议日志均保存在本机 protocol/account.local.json 与 protocol/live 目录中。页面状态接口不返回密码、验证码、token、AD凭据或完整设备响应。浏览器未使用 localStorage 保存这些数据。API要求正确的本机Host、Origin及每次进程生成的请求校验值，静态文件只开放明确列出的页面资源。

**关机续期效果仍未验证。** 页面不展示虚构的关机倒计时。历史“连接成功”只表示主通道连接与上报完成。

检查：

```powershell
python -X utf8 web/test_web.py
```

后端检查使用独立临时配置和模拟客户端，不发真实短信、不访问生产服务。
